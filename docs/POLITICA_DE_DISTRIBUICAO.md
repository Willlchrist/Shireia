# Política de distribuição do Shireia

O Shireia é um projeto de emulação gratuito e de código aberto, mantido publicamente por Willlchrist.

O projeto não comercializa versões oficiais, não cobra pelo acesso ao código-fonte e não exige pagamento para utilizar suas versões disponibilizadas gratuitamente.

O código-fonte permanece sujeito às licenças de software livre aplicáveis, incluindo a GPL e as licenças dos componentes de terceiros.

Esta política não altera as permissões de redistribuição comercial concedidas pelas licenças aplicáveis ao código.

O nome, o logotipo e a identidade visual do Shireia são tratados separadamente das licenças de software, conforme os direitos efetivamente existentes sobre esses elementos.

O Shireia não é afiliado, patrocinado ou endossado pela Nintendo. Esta política descreve a intenção de distribuição do projeto e não garante proteção contra processos ou reivindicações jurídicas.
